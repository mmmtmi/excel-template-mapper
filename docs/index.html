Go + GraphQL 深掘り

excel-template-mapper 教材

対象: Go の基礎を理解し、簡単な Todo アプリなら自力で作れる人。 目標: GraphQL サーバーの構成、Resolver と Service の責務分離、Excel から JSON へ変換するロジックを、時間制限なしで順に理解する。

教材で使うリポジトリ

https://github.com/mmmtmi/excel-template-mapper

コード全体を確認したい時、GitHub 上で差分や履歴を見たい時はここを参照します。

この教材の前提

  • 環境一式は Clone または配布ZIPから用意する
  • Go の文法、構造体、interface、error handling は理解している前提で進む
  • GraphQL は未経験でもよいが、HTTP API の基本は知っている前提で進む
  • 時間制限は設けない。理解できるまで読み、動かし、戻って確認する

進め方

  1. 解説を読む
  2. 実際のコードを読む
  3. 再度解説で整理する
  4. 最後に改善案を .md にまとめ、PR 形式で提案し、可能なら実装まで進む

各レッスンは「概念の解説 -> 該当コードを読む -> 再度整理する」の順で進めます。読む前に概念を説明し、読んだ後に設計意図を確認する流れを意識します。
