この回のゴール

  • 入口が違っても service 層を共有できる理由を説明できる

実行コマンド

go run cmd/etm/main.go --template demo_v1 internal/excel/Book1.xlsx

読むファイル

  1. cmd/etm/main.go
  2. internal/service/processor.go

比較ポイント

  • GraphQL 版は resolver が入口になる
  • CLI 版は command parsing が入口になる
  • どちらも最終的には processor に処理を委譲する
