Lesson 5

Processor を読む

この回では、このアプリの業務ロジックの中心である processor を追います。

この回のゴール

  • ProcessExcelOnly と ProcessWithTemplate の違いを説明できる
  • Template と Rule がどのように変換へ使われるか説明できる
  • validation と transform の流れを追える

読むファイル

  1. internal/service/processor.go
  2. internal/model/template.go
  3. internal/model/rule.go

処理の流れ

template を取得
  -> rules を取得
  -> ReadOptions を組み立てる
  -> Excel を読む
  -> 必須 header を検証する
  -> row ごとに rule を適用する
  -> transform を適用する
  -> 必須値を検証する
  -> JSON 用の map を返す

注目する関数

  • buildReadOptionsFromTemplate
  • requiredHeaderRules
  • validateRequiredHeaders
  • validateRequiredValues
  • applyTransform
