Lesson 6

Excel Reader を読む

この回では Excel をどのように「表」として読み替えているかを確認します。

この回のゴール

  • ReadOptions の意味を理解する
  • header row と data start row の違いを説明できる
  • Excel の生データを row/column の辞書へ変換する流れを追える

読むファイル

  1. internal/excel/reader.go
  2. internal/excel/Book1.xlsx

理解すべきこと

  • どのシートを読むか
  • header row をどう抽出するか
  • 空 header をどう扱うか
  • 各行を map[header]value にする理由

Processor との接続

Processor は reader から「整形済みの表データ」を受け取ります。つまり reader の責務は Excel ファイルの物理構造を隠蔽することです。

Excel file
  -> reader
  -> headers + rows
  -> processor
  -> rules を適用

考える問い

  1. 紙の帳票に近い Excel を JSON 化する時、なぜ header ベースの読み方が有効なのか
  2. 複数の表領域が 1 シートにある場合、現状の設計はどこで破綻するか
  3. CELL type を追加するなら reader と processor のどちらへ責務を置くべきか
