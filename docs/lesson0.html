Lesson 0

準備する

この回は環境構築の確認と、これから読むコードの前提整理です。Go 基礎は理解済みという前提で進みます。

この回のゴール

  • 必要な開発ツールがそろっている
  • プロジェクトを開き、生成コマンドを実行できる
  • .env と Docker Compose の役割を理解する

必要なツール

  • Go
  • Git
  • Docker Desktop または Docker Engine + Compose
  • VS Code などのエディタ

確認コマンド

go version
git --version
docker --version
docker compose version

Clone して開く

git clone <この教材のリポジトリURL>
cd excel-template-mapper

VS Code ではプロジェクトルートを開き、内蔵ターミナルを使います。

.env を作る

SQL_USER=app
SQL_PASSWORD=app
SQL_ADDR=localhost:3306
SQL_DBNAME=excel_template_mapper
PORT=8080
  • SQL_USER / SQL_PASSWORD: MySQL 接続情報
  • SQL_ADDR: アプリから見た DB の接続先
  • SQL_DBNAME: 接続する database 名
  • PORT: GraphQL サーバーの listen port

生成コマンド

go mod tidy
go run github.com/99designs/gqlgen generate

この教材では生成物を手で書かず、自分の環境で再生成します。

最初に把握するディレクトリ

  • cmd/api: サーバー起動
  • graph: GraphQL schema と resolver
  • internal/service: 変換ロジック
  • internal/store/mysql: DB アクセス
  • internal/excel: Excel 読み取り
